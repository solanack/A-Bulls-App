# A Bulls App - Living Universe Direction

This is the compact engineering contract for the approved read-only universe.

## Non-negotiable boundaries
- Read-only: no wallet connection, custody, signing, swaps, copy trading, token launch, liquidity execution, or transaction approval.
- Retired shooter/LIFE/Bull Invaders surfaces must not return.
- Extend the current particle Field, Grey organism, Replay, Evidence, Trickster/Create, and single Intelligence Worker; do not create a second product.
- Grey speaks observed/sourced facts. Provider-reported context is identified as provider-reported and never blended into independently observed chain evidence.
- Decorative fabric is DUST only and never promoted into evidence.

## Public universe topology
Galaxy Zero exposes exactly three research destinations:
- **Fomo** — trader research lens. Up to 50 cached Fomo all-time trader identities become public-wallet STARS when a public wallet address is supplied by the provider record.
- **pump.fun** — launch-origin galaxy of token PLANETS.
- **PonsFamily** — public name for internal galaxy id `pons`; qualifying verified PONS-origin token PLANETS are ranked by fresh reported 24h volume.

`solana-core` remains an internal compatibility/provenance namespace for generic Solana evidence. It is not a public Galaxy Zero destination. Generic Solana wallets, tokens, Replay, and Evidence remain queryable.

Fomo Galaxy is a research lens, not a launch origin. A token shown inside a Fomo trader system keeps its actual known launch origin; unknown generic Solana origin remains `solana-core` rather than becoming Fomo.

## Token planet entry
A token PLANET is navigable. Entering it keeps the token central while retained public wallets become STARS around it. Star size can use only an explicitly supported observed relationship measure. Missing holder/wallet evidence produces an honest empty sky. Planet entry and rendering must not trigger passive provider fan-out. Indexed current trades may appear as COMETS and observed liquidity as an ASTEROID BELT.

## Fomo Galaxy and trader systems
The Fomo all-time top 50 is a discovery layer sourced from the independent `fomoapi.io` feed and cached in D1. Page views never replay a logged-in Fomo session and never require a Fomo user session.

Fomo rank, PnL, profile, follower, volume, and reported top-token fields are labeled **Fomo-reported / as reported**. They are not A Bulls App proof of profit, identity, skill, strategy, or wallet control.

Entering a Fomo trader STAR creates a bounded research system:
- selected trader STAR at the center;
- up to 10 token PLANETS that can be mapped to public token addresses from Fomo-reported top-token context and/or retained A Bulls App wallet-token observations;
- up to 3 latest trade COMETS from retained A Bulls App public-chain evidence;
- Replay, Evidence, Compare, and Trickster/Create inherit the selected public wallet + token context when available.

If a reported token cannot be mapped to a public address, it does not become a token planet. If chain history is incomplete, the system says so. No copy-trade action exists.

## PonsFamily
PonsFamily keeps internal id `pons` to preserve D1 identity and factory-origin history. Membership is automatic and evidence-gated:
- verified PONS V1/V2 launch-origin receipt required;
- fresh market cap **above $75,000**;
- fresh holder count **above 750**;
- fresh reported 24-hour volume required;
- ranking primarily by **24-hour volume descending**;
- maximum 50 qualifying planets;
- two-cycle entry/exit stability may remain to prevent visual thrash;
- FDV never substitutes for market cap;
- missing holder/market evidence does not qualify.

The old pinned $PONS teaching-token fallback is retired. $PONS appears only when it qualifies like every other PonsFamily planet.

## Trickster / memory layer
Replay is the timeline primitive. Trickster/Create builds cited stories from bounded Replay evidence; selecting a Fomo trader and one of their token planets may prefill the wallet+mint pair. Every narration claim keeps receipts. Thesis remains the memory layer for what users claimed and what was observed later. No parallel storytelling product is introduced.

## Watchlist
The local-first watchlist can save token PLANETS and public-wallet STARS, including Fomo trader stars when a public wallet address exists. Saved references are not proof of current evidence.

Grey uses server-side ElevenLabs synthesis when configured, with a dedicated Grey voice profile and browser speech fallback. The ElevenLabs API key stays server-side. Effects should be subtle, intelligible, calm, and non-human in atmosphere rather than distorted/metallic.

## Performance and data cost
Preserve mobile, reduced-motion, save-data, and the known-good Seeker WebGL lifecycle. Do not increase Field particle budgets merely to support Fomo or PonsFamily. Fomo provider refreshes are bounded, cache-first, and guarded by a monthly credit breaker. PonsFamily market/holder enrichment is scheduled and bounded; public reads are D1-only.
