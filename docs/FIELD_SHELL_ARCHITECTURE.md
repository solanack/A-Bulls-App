# Universal Particle Field Architecture

## Product rule
The Solana particle field is the application shell, not a product named Universe. Users enter the field and all retained capabilities live as modes, selections, overlays or transitions inside it.

## Field modes
- Explore/Search
- Intelligence
- Temporal Replay
- Compare
- What If
- Market Sequences
- Create / Trickster
- Evidence / Verify
- Wallet, token, NFT and program intelligence
- Games / Bull Invaders

## Interaction contract
`ENTER FIELD -> SEARCH/SELECT -> FIELD REORGANIZES -> INVESTIGATE -> PLAY/REWIND -> COMPARE/WHAT IF -> CREATE -> SHARE/VERIFY`

The normalized evidence layer remains canonical. The renderer never invents coverage, price, identity, causation or activity. A bounded/sampled observation window must remain disclosed as bounded/sampled.

## Responsive contract
Desktop is a true full-viewport workstation. Phone uses the same field and capabilities with adaptive particle density, camera, gestures and workspace presentation. At 760 CSS px and below the dedicated phone layout applies; it is not a separate reduced product.

## Engine boundaries
The field shell does not replace Intelligence Mesh, Temporal Replay, Token Market, Market Sequences, Evidence Ledger, Trickster or Bull Invaders. It hosts them. Bull Invaders competitive invariants remain untouched.

## Current implementation
`js/field-shell.mjs` owns universal search, field-mode command dock, persistent field host and contextual workspace. `js/universe-experience.mjs` remains mounted in the persistent field host while Intelligence, Trickster and Games mount into contextual workspaces. Closing a workspace returns to the field rather than navigating to a conventional home page.

## Release rule
This architecture is development-only until explicitly authorized. No merge, production deployment, migration application or external retrieval enablement is implied by this document.
